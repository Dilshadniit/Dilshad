# Anomaly Detection & Time Series (DA-AG-018)

PW Skills Data Analytics assignment covering anomaly detection (Isolation Forest, LOF, DBSCAN) and time series (decomposition, stationarity, ARIMA/SARIMA/SARIMAX).

## Contents
- `notebooks/assignment.ipynb` - code for Q6 to Q10
- `outputs/` - saved plots
- `DA-AG-018_Answers.pdf` - full answers (Q1 to Q10)

## Datasets
- AirPassengers: https://raw.githubusercontent.com/jbrownlee/Datasets/master/airline-passengers.csv
- NYC Taxi Fare: Kaggle "New York City Taxi Fare Prediction" (`train.csv`)

## Tools
Python, pandas, NumPy, scikit-learn, statsmodels, matplotlib

## Run
```bash
pip install pandas numpy scikit-learn statsmodels matplotlib
jupyter notebook notebooks/assignment.ipynb
```
